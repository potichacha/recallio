### QCM

**Q : Combien font 2 + 2 ?**
- [ ] 3
- [x] 4
R : Deux plus deux font quatre.

**Q : Quelle est la couleur du ciel par beau temps ?**
- [x] Bleu
- [ ] Vert
R : Le ciel est bleu.

**Q : Quels nombres sont pairs ?**
- [x] 2
- [ ] 3
- [x] 4
R : 2 et 4 sont divisibles par deux.

**Q : Combien de jours compte une semaine ?**
- [ ] 5
- [x] 7
R : Une semaine compte sept jours.
