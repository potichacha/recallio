Parcourir une liste

La boucle for-each

Elle passe sur chaque élément, dans l'ordre. Change la liste, puis lance le programme.

Main.java

1void main() {
2  var notes = List.of(12, 15, 9);
3  for (var note : notes) {
4    IO.println("Note : " + note);
5  }
6}

Sortie · 0,4 s

Note : 12
Note : 15
Note : 9
