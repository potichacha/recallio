Java · Parcourir une liste

La boucle for-each

Pour passer sur chaque élément d'une liste, tu n'as pas besoin d'un compteur. La boucle for-each prend les éléments un par un, dans l'ordre.

À retenir : on lit « pour chaque note dans notes ». Tu ne peux pas modifier la liste pendant que tu la parcours.

Teste-toi

Combien de fois la boucle tourne-t-elle ?

Main.java

1void main() {
2  var notes = List.of(12, 15, 9);
3  for (var note : notes) {
4    IO.println("Note : " + note);
5  }
6}

Sortie · 0,4 s

Note : 12
Note : 15
Note : 9
