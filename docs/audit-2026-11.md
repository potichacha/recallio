# Audit du 2026-11-10 : ce qu'il reste à améliorer

Revue du projet avant de reprendre le contenu : le code, la stack locale mesurée, les écrans capturés sur ordinateur et
sur mobile, et les 12 041 cartes de Java, Go et « Programmer de zéro ». Chaque élément porte un numéro définitif, que
reprend la feuille de route de `CLAUDE.md` (section 9, « Avant le déploiement », étape 8).

## Ce qui a été mesuré

- **Backend** : rien à optimiser aujourd'hui.
  - Les deux requêtes les plus lourdes de la file de révision prennent 2 à 3 ms sur les 7 072 cartes Java.
  - Les routes authentifiées répondent en 6 à 73 ms à travers nginx (médiane de 6 appels) : 35 à 41 ms pour la file
    d'un sujet, 68 ms tous sujets confondus, 73 ms pour les statistiques de révision.
  - Limite : le compte de test n'avait aucun historique. À remesurer avec des milliers de révisions.
- **Front** : un seul fichier JavaScript de 1 037 Ko, 291,6 Ko compressés pour un budget de 300 ; les pages s'affichent
  en 0,5 à 0,8 s en local, sans erreur dans la console.
- **Cartes** :

| | Java | Go | Programmer de zéro |
|---|---|---|---|
| Cartes | 7 033 | 4 893 | 115 |
| Cartes avec des choix | 21 % | 18 % | 60 % |
| La bonne réponse est la plus longue (QCM à une réponse) | 53 % | 56 % | 41 % |
| QCM à plusieurs bonnes réponses | 525 | 657 | 1 |
| Même question dans deux notions | 25 | 16 | 0 |
| Réponses de plus de 400 caractères | 375 | 264 | 0 |

Le vouvoiement et les questions vagues sont repérés par des motifs de texte : ces comptes sont approximatifs. Les
cartes n'ont pas été relues une à une pour leur exactitude technique.

## Ce qui va bien, à ne pas toucher

- Le bac à sable : sans réseau, en lecture seule, mémoire, processeur et nombre de processus bornés, capacités retirées.
- Les jetons en `sessionStorage`, l'audience du JWT vérifiée, les entrées bornées, les images scannées, Dependabot.
- Les vrai ou faux équilibrés (46 à 50 % de « vrai »), une explication sur chaque carte, des leçons courtes (250 mots
  en médiane).
- La carte de révision sur mobile, la navigation, le Tour en deux colonnes sur ordinateur.
