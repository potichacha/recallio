# Logos des sujets

Les logos des langages et des outils du catalogue (ADR 0052), servis tels quels par l'application.

- **Source** : [devicon](https://github.com/devicons/devicon), version 2.16.0, sous licence MIT.
- **Marques** : chaque logo reste la marque de son propriétaire (Oracle pour Java, la Python Software Foundation pour
  Python...). Ici, un logo ne sert qu'à désigner le sujet qui porte son nom.
- **Ajouter un logo** : déposer `<slug du sujet>.svg` ici, puis ajouter son slug à `SUBJECT_LOGOS`
  (`src/subjects/subjectLogos.ts`). Sans logo, un sujet a l'icône de sa catégorie.
